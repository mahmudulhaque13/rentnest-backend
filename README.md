# RentNest Backend API

A secure and scalable RESTful backend API for a rental property management platform built with **Node.js**, **Express.js**, **TypeScript**, **Prisma ORM**, and **PostgreSQL**. The system supports role-based access for **Tenants**, **Landlords**, and **Admins**, along with property management, rental requests, Stripe payment integration, reviews, and administrative controls.
